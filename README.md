# 孢粉分析工作台 · 正式版（v1.0.0）

Windows 本地桌面软件，中文界面。支持原始计数计算百分比，或直接导入已有百分比，继续绘制孢粉地层图、进行 CONISS 地层约束聚类、人工分带、PCA 主成分分析、孢粉出现分布图和论文图导出。

## 启动

将 `PollenStudio-1.0.0-Windows-x64.zip` 完整解压，双击文件夹内的 `PollenStudio.exe`。本项目生成的位置为 `dist/v1.0.0/PollenStudio/PollenStudio.exe`。保留整个 PollenStudio 文件夹，不能只复制 exe。无需安装 Python、R 或联网。本机 Windows 11 已验证，其他 Windows 版本尚未实机测试。

“帮助”菜单提供离线中文快速入门、完整说明和版本信息，按 F1 可打开快速入门；软件外也可双击“欢迎使用.html”查看说明。模板、模拟项目、模拟数据与分析结果、示例图件分别在“模板”“示例项目”“示例数据与结果”“示例图件”中。

“文件 → 另存为”或 Ctrl+Shift+S 可保存项目副本，Ctrl+S 保存当前项目。修改随附示例时可先另存为自己的项目。

## 数据与计算

1. 使用“下载模板”，或导入两层表头 Excel / CSV。
2. 第一列为“深度/年代”，项目内选择它代表深度还是年代，并设置单位。无需样品编号。
3. 第一层为木本、灌木、草本、水生、蕨类、未定类群；第二层是具体类群。支持 Excel 合并分组表头。
4. 每行一个样品。导入时选择“原始计数”或“已有百分比”，后者的操作见下节。原始计数必须为非负整数，空白表示缺失，0 表示有效零计数。
5. 在右侧勾选进入计算基数的类群。百分比 = 类群计数 / 本行所选类群计数和 × 100。
6. 非基数类群同样计算百分比，可能超过 100%。基数缺失或为零时不计算，不自动补零。
7. 数据错误阻止结果导出，双击检查报告可定位；原始内容仍可保存为项目。
8. 计数模式的 Excel 结果含原始计数、百分比、实际基数、类群设置、计算说明和检查报告。
9. `.pollen` 项目保存数据、分组、计算方案、绘图设置、聚类结果、人工边界调整记录、PCA 设置与结果及出现分布图设置。当前没有通用撤销和完整数据编辑历史，请及时保存项目副本。

## 已有百分比直接导入

1. 点击“导入 Excel / CSV”，选择数据工作表，在“数据类型与数值单位”窗口选“已有百分比（直接绘图与分析）”。核对数值预览后点击“按预览应用”。两层表头和深度/年代格式与计数模板相同。
2. 普通数字有两种解释：**百分数：12.5 表示 12.5%**；**比例数：0.125 表示 12.5%**。普通数字不会根据大小自动猜测单位，避免把低丰度的 0.125% 放大为 12.5%。
3. Excel 真正的百分比单元格格式会单独识别：底层值 0.125、显示 12.5% 的单元格导入为 12.5%。带 `%` 或 `％` 的文本也按百分数解释，不因单位选项重复乘以 100。带公式的工作表须先在 Excel 中粘贴为数值。
4. 导入后统一按百分数编辑：表格中的 12.5 就是 12.5%。不再除以任何基数，不重新归一化，也不要求每行之和为 100%；筛除分析类群后仍保留原值。单值超过 100% 会提示核对，原值保留。空白和有效零值分别处理，负值和非数值须修正。
5. 可直接进入“孢粉图谱”“聚类与分带”“PCA 分析”和“出现分布图”。聚类与 PCA 初始选择全部类群，可独立筛选；原有平方根变换和标准化选项继续有效，不改变已保存的源百分比。
6. 原始粒数和实际基数标为未知，基数选择、基数方案、低计数阈值和“原始计数大于零”检出选项停用。出现分布图使用未四舍五入的导入百分比大于零判为检出，0.002% 即使显示为 0.00% 仍检出；缺失百分比显示灰色 ×。
7. 数据页面右侧“数据类型与单位”可重新解释已导入或粘贴的表格，先查看预览再应用。这是对现有数字指定含义；将计数换算为百分比仍需在原始计数模式中设置基数。已有百分比不能反推粒数，含数据的百分比项目不提供直接切回计数的选项，需要时重新导入原计数文件。
8. 项目保存输入类型与单位来源，旧项目继续按计数打开。百分比 Excel 导出包含“导入百分比”“百分比结果”和说明，不产生原始计数或基数明细；两张数据表均存储百分数，显示小数位不改变实际存储精度，再次导入不会重复换算。
9. 程序目录附“孢粉百分比模板.xlsx”，以及普通百分数、比例数、Excel 百分比格式三种模拟数据文件和可直接打开的百分比分析示例项目。

## 论文默认版式

- **最多 60 个类群放在同一张图中，不分幅**。超过 60 个展示类群时提示手动取消部分展示勾选，不静默遗漏。
- 基础图幅 **18.3 × 12.5 厘米**。启用密集排版时，超过 24 个类群会适度增加图宽；自动建议宽度最大 25.5 厘米，60 类群默认 25.5 × 12.5 厘米。手动设置更大宽度时按设置值绘制。
- 默认按各类群在全部样品中的最大百分比分配列宽。低占比类群保留可读窄列，高占比类群获得更多空间；只改变布局，不改变计数、百分比及计算基数。
- 默认低占比阈值为 2%，可调整。阈值指该类群所有样品百分比的最大值。也可选择等宽分配，并使用单类群“列宽权重”调整分配优先级。
- 全部类群共用同一纵轴范围、固定步长和小数格式。样品按真实深度或年代定位，保留不等距采样信息。
- 常规图名称 45°、字号 7.5 磅、刻度 6.5 磅。超过 24 类群且启用密集排版时，名称自动竖排、字号最多 7 磅、刻度最多 6 磅，并精简间距。实际字号、角度及尺寸显示在预览上方。
- 常规轮廓与坐标线为 0.45 磅；密集图轮廓线最多 0.4 磅。坐标标题默认 8 磅。
- 窄列仅标注横轴上限，数值竖排；宽列保留常规刻度。各列百分比范围不同，横向物理宽度不是统一百分比比例尺。
- 默认西文无衬线字体，中文自动使用中文字体；也可选择西文衬线、微软雅黑、宋体。
- 默认填色＋轮廓线，各类群横轴自动设置。独立刻度需要分别读取，不能根据曲线宽度直接比较不同类群的丰度。
- 原来图内的操作说明不再印入论文图；相关信息在软件界面中提示，绘图设置可随项目保存。
- 打开旧项目时，计数、基数、标题、类群颜色及展示选择保留，旧版排版和自动分幅参数升级为单幅自动列宽布局。
- “恢复单幅默认版式”可恢复尺寸、字号、线宽、间距及列宽分配设置，不改变计算规则。

这些是便于使用的通用初始参数，投稿时仍应按目标期刊要求调整。双栏宽度参考 [Nature 制图指南](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)，不代表通用期刊的统一标准。

## 绘图操作

1. 进入“孢粉图谱”，点击“更新图谱”。
2. 左侧控制展示类群及组内顺序，绘图勾选不改变百分比基数。
3. 右侧调整整体与单个类群样式：颜色、范围、刻度、曲线形式、放大倍数及列宽权重。
   “整体样式”顶部的“统一曲线形式”可一次将所有类群（包括未展示类群）改为填色＋轮廓线、折线或水平柱线。选择后点击“更新图谱”查看结果，设置随项目及绘图样式保存。仍可在“当前类群”中单独修改；各类群形式不同时，整体选项显示“各类群分别设置”。
4. 六组默认颜色为木本 `#67A583`、灌木 `#A2C986`、草本 `#49C2D9`、水生 `#7B95C6`、蕨类 `#FFC1A6`、未定类群 `#F47254`。旧项目中沿用的原默认色会升级为这套配色，自定义颜色保留；点击左侧“恢复六组默认配色”可统一应用新版配色并清除单类群颜色覆盖。
5. 点击图谱顶部或右侧整体样式中的“纵轴坐标设置”，打开独立窗口。窗口显示当前坐标类型、单位和样品范围，可手动输入最小坐标值、最大坐标值、刻度间隔，并选择坐标是否向下增加。支持小数和科学计数法；留空的项目自动设置。“恢复自动范围与刻度”清空三项数值，点击确定后生效。已有图谱会自动更新，纵轴设置随项目和绘图样式保存；尚未绘图时先保存设置，随后点击“更新图谱”。
   全部孢粉列、组合带和聚类树同步使用该纵轴，样品仍按真实深度/年代定位。范围外样品仅在图中隐藏，原始数据及聚类分析输入保留。最大值须大于最小值，间隔须为正数，显示范围应包含样品，刻度数量最多 150 个。页面留白另在右侧“页边距设置”中调整。
6. “适应整幅”显示完整页面，工具栏提供中文说明的恢复、返回、前进、平移和框选缩放。密集图可提高预览缩放比例查看细节，鼠标指向曲线面板可查看完整类群名称与原始百分比。
7. 缺失值处断线、停止填色；不自动补零、插值或平滑。重复坐标需先核对，不自动平均。未排序数据仅在绘图副本内排序。
8. 放大曲线以浅色、虚线及倍数标记叠加，原始百分比不变。手动横轴上限不足时提示，不静默截断。
9. 修改数据或设置后必须更新，才能导出。导出始终采用完整的设置范围，预览缩放不会裁切论文图。
10. 项目保存完整设置；`.pollenstyle` 可将样式复用于其他项目，类群选项按名称匹配。

## 导出

- 默认导出 PDF：所有展示类群位于同一页矢量图，字体嵌入。
- PNG：可选 300 / 600 分辨率，输出一个完整图片文件。
- SVG：输出一个完整矢量图并保留可编辑文字；在其他设备编辑时需具备相应字体，最终投稿推荐 PDF。
- 导出仅生成所选图像或文档，不再附带 `.plot.json` 参数文件。需要保留数据及绘图设置时，使用“保存项目”或“保存绘图样式”。旧版生成的参数文件可自行删除，不影响 PDF、PNG、SVG 的使用。

程序目录附有 16 类群和 60 类群的模拟项目、Excel 模板、单幅默认样式、聚类与人工分带示例及图谱。“示例数据”按钮加载 60 类群示例，仅展示功能，不代表真实岩芯或研究结论。

## 聚类与分带

1. 完成数据检查和百分比计算后，进入“聚类与分带”。计数模式初始分析类群采用当前基数勾选，可独立调整，不改变计算基数或图谱展示选择；“按基数选择”可再次同步。已有百分比模式初始选择全部类群，不提供按基数选择。
2. 样品默认全部参与。取消勾选可明确排除样品，原表内容保留。至少需要 2 个有效样品，本版单次最多 2000 个样品。分析按真实深度/年代递增排序，仅合并相邻组，不重排原始表。
3. 默认对原百分比除以 100 后开平方，使用欧氏距离，再执行 CONISS。可选择不做平方根变换，或使用“欧氏距离平方”。筛除分析类群后不重新归一化；改变百分比基数会改变分析输入。空白不补零，缺失须先修正或明确排除。
4. 点击“计算 CONISS”。计算在后台进行，可取消。选择“算法带数”即可更新分带，无须重新计算树；默认 3 带，有效样品不足 3 个时按样品数限制。该初始值不表示自动判定了最佳带数。“带数参考（断棍模型）”提供离差变化与参考曲线，需结合孢粉组合、地层证据和研究目的判断。
5. **带号从深部／较老端的Ⅰ带开始，向浅部／较年轻端递增。** 双击带名可命名。这里的较老端按年代数值较大解释，使用公历年份等反向编码时应先转换坐标含义。
6. 在边界列表选择后可修改或删除，也可新增边界。操作自动切换为人工分带，保留原始算法树和调整记录；“恢复算法分带”重新采用算法边界。重新计算分析会回到算法分带，旧人工调整记录仍保存在项目中。
7. 算法边界显示在两侧样品坐标的中点；人工边界可输入有效范围内的数值。软件列出两侧样品区间。它们是分带位置，不能替代有独立证据的精确事件年代。坐标恰在边界上的样品归入较深／较老一侧。
8. 进入“孢粉图谱”点击“更新图谱”，右侧显示组合带及聚类树，并可在孢粉图和组合带栏中显示分带线；聚类树中不显示分带线。树叶与样品真实坐标对齐，被排除样品不出现在树中。全部孢粉列仍在同一张图中，保留原物理列宽，图幅增加容纳右侧栏所需宽度。孢粉图右边缘与组合带栏默认仅留 1.2 毫米，不再叠加原图右页边距；60 类群默认整幅约 28.12 × 12.5 厘米。
9. 默认聚类树宽 1.5 厘米，分带线采用实线。可开关树、组合带、分带线，调整树宽、带栏宽、线型、线宽和颜色。已保存的项目沿用其原设置。过窄组合带可能容纳不下带名或带号，可增大图高、调整分带数量，并在分析表中核对所有带。图谱缩放不会影响完整导出。
10. “导出分析结果”单独生成 Excel，含样品分带、边界区间、合并过程、参与类群、分析百分比、分析设置、人工调整记录和带数参考。图谱导出只生成所选 PDF / PNG / SVG，不自动附带分析表或参数文件。

改动计数、基数、坐标、分析类群、排除样品或变换／距离后，旧结果失效，需重新计算。仅修改绘图颜色、线型、带数或人工边界不重算聚类树。项目文件保存并核验结果指纹，打开后可继续编辑有效结果；旧版项目没有分析结果时，原有计算与绘图功能可正常使用。

本版独立实现相邻约束的 CONISS 递推。默认距离约定对齐 `rioja::chclust(dist(sqrt(百分比/100)), method="coniss")`；横轴“累计总离差”按该递推累计，不能将默认欧氏距离模式的数值直接解读为原变换矩阵的平方和。“欧氏距离平方”模式才对应该矩阵的组内平方和尺度，两种模式可能产生不同树和边界。精确并列值按坐标较小端优先合并。

算法已用手算、独立成对离差参考及 rioja 1.0-7 原生核心对照验证，52 组对照覆盖两种距离约定、随机矩阵及并列值；最大差异约 7.1×10⁻¹⁵。参考资料：[rioja 手册](https://cran.r-universe.dev/rioja/doc/manual.html)、[CONISS 核心](https://github.com/cran/rioja/blob/master/src/chclust.cpp)、[断棍模型实现](https://github.com/cran/rioja/blob/master/R/bstick.r)。软件运行无需安装 rioja 或 R。

## 中文与浅色界面

五个工作区保持浅色模式。绘图工具栏、悬停说明、字体选项及标准对话框均使用中文。数据里的拉丁分类名、单位符号、CONISS、PCA、PC1 等方法缩写和通用文件扩展名按原值显示。

## PCA 主成分分析

1. 导入数据、确定百分比基数后，进入“PCA 分析”。左侧勾选参与分析的类群，计数模式初始采用当前百分比基数的类群选择；“按基数”可再次同步。已有百分比模式直接使用导入值，初始选择全部类群。PCA 类群选择与孢粉图谱展示勾选独立，筛选后不重新归一化。样品选择与自定义分组在左下角按钮中设置，原 Excel 两层表头与深度/年代格式保持原样。
2. 默认对百分比除以 100 后开平方，再按类群中心化，进行 SVD 分解。可选择不做平方根变换；“按类群标准差标准化”默认关闭，勾选后在中心化基础上除以样本标准差（n−1）。这些是可选分析口径，不能据此声称完整复现某篇论文的未披露参数。
3. 至少需要 3 个有效样品、2 个有变化的类群和 2 个非零主成分；单次最多 2000 个样品。全零和无变化类群会排除并记录；缺失百分比须修正或明确排除样品/类群，不自动补零。坐标重复可用于 PCA，样品通过内部标识区分；地层聚类的重复坐标规则仍保持原样。
4. 点击“计算 PCA”，后台计算后自动生成左右双图：左侧“孢粉类群相关载荷”，右侧“样品分布”。图中均标注所选主成分及解释率，默认 PC1—PC2。两图分别使用相关系数坐标和样品得分坐标，各自保持横纵等比例；坐标范围可以单独设置。计算基于全部参与样品，样品分组不参与 PCA 分解。
5. 左图箭头表示每个变换后类群与主成分得分的相关系数，并非直接绘制原始特征向量；原始载荷与相关系数分别在数值页和 Excel 中提供。默认显示二维相关系数平方和最高的前 20 个类群，它反映所选二维平面对该类群的表达程度，不是统计显著性排名。可显示全部或手动选择；隐藏箭头不改变计算。
6. 箭头默认深灰色，也可按六类孢粉配色；西文名称默认斜体。名称自动避让。“箭头与标签”窗口可设置显示选择和标签偏移；关闭平移、缩放模式后，也可直接拖动类群标签，松开后保存位置并更新图形。“重置标签位置”恢复自动避让。偏移按未翻转的相关系数坐标保存，切换主成分后建议重置标签位置。
7. 右图默认按现有有效组合带着色，包括人工调整后的边界和带名。尚未分带时暂按未分组显示；已有分带结果失效时会要求重算分带，或切换为不分组/自定义。未参与现有聚类的 PCA 样品单独标为“未分带”，不外推其归属。改变分带、组名或颜色只需更新图形，无须重新分解 PCA。
8. **不绘制椭圆。** 可在“样品选择／自定义分组”中填写组名，再将“样品分组”切换为“自定义分组”。组颜色独立于六类孢粉配色，可自行设置。可选择在散点旁显示样品深度/年代；鼠标在样品图区移动时显示邻近样品的原表行、坐标、分组和得分。
9. 默认双图整幅 18.3 × 9.5 厘米、白色背景、名称 7.5 磅、刻度 7 磅、坐标标题 8 磅、箭头/坐标线宽 0.6 磅、样品点面积 18 磅²。可以调整尺寸、字体、颜色、线宽和点大小，也可只输出其中一个面板。单图时可手动将图宽缩到 10 厘米以减少横向留白。a、b 子图编号可关闭。
10. 支持选择其他主成分组合，并同步翻转两图的横轴或纵轴。PCA 主成分的正负号本身任意；本软件固定每个主成分最大绝对载荷为正，以保证重复生成的一致性。翻转只影响绘图，数值表保留计算方向，Excel 分析说明记录图形翻转设置。
11. “解释率”“样品得分”“类群载荷”页可查看结果，后两者显示当前所选两个主成分的原始方向数值。独立 Excel 导出包含全部主成分、特征值、解释率及累计解释率、样品得分、原始载荷、类群相关系数、参与/排除设置、原百分比和最终中心化/标准化输入矩阵。
12. 修改计数、基数、分析类群、排除样品、变换或标准化设置后，PCA 结果失效，须重新计算；仅改变图形样式、分组或箭头展示时点击“更新图形”。项目保存完整设置和经过指纹核验的结果，旧版项目可直接打开，新增 PCA 字段初始化为空。
13. 图形可导出单个 PDF、SVG 或 300/600 分辨率 PNG，图像导出不附带参数文件；分析 Excel 仅在独立导出时生成。导出恢复完整设置范围，预览中的平移和缩放不会裁切论文图。程序目录含“PCA双图示例（模拟数据）.pollen”、图像和 Excel，示例不代表真实岩芯或研究结论。

数值实现遵循中心化 SVD PCA 的定义，特征值为奇异值平方除以 n−1。已以手算矩阵、独立协方差矩阵特征分解、重构误差、得分协方差和相关系数直接计算进行核对，并检查单位方差标准化与未标准化两种口径；本机未安装 R，因此不将这些验证表述为运行过 R 的对照。定义参考：[R 官方 prcomp 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/prcomp.html)。

## 孢粉出现分布图

1. 进入“出现分布图”，勾选展示类群、选择样品后点击“生成图形”。横轴为等间距的类群列，纵轴为真实深度/年代；点的位置不等距重排，不插值、不连接检出区间。图中符号大小统一，不表达丰度。出现图样品和类群选择独立于百分比图谱、PCA 和聚类的勾选。
2. 检出依据有两种：计数项目默认“原始计数大于零”，直接使用非负整数计数，不要求选择百分比基数；“实际百分比大于零”使用当前基数计算出的完整精度百分比。有效、非零基数下，两种判定一致。1 粒/50000 粒对应 0.002%，即使显示为 0.00%，仍判为检出。计数项目使用百分比检出而未选择基数时提示先设置基数。已有百分比项目直接使用导入百分比判定，不要求基数，不可使用原始计数检出。
3. 有效零值留空，原始计数缺失显示浅灰色 ×；百分比因基数为零/缺失而无法计算时也显示 ×，悬停及 Excel 保留具体原因。无效或负计数须修正，不能自动转成零。计数模式的绘图可用性只取决于参与绘图的计数与坐标，不受其他类群基数缺失影响。
4. 初始展示全部类群，包括全零类群。“隐藏全零类群”只隐藏所有参与样品均可判定、且全部未检出的类群；含缺失或无法判定的类群保留。重复深度/年代会提示核对或明确排除，避免同一位置的符号重叠；未排序数据仅在绘图副本内排序，原表保留。
5. 默认每排最多 40 类群，自动均衡分排；41 类群为 21/20，60 为 30/30，80 为 40/40，81 为 27/27/27，100 为 34/33/33，121 为 31/30/30/30。每排上限可在 5—40 之间调整。所有排合成一张图、单个输出文件；出现分布图不采用百分比图谱的 60 类群单幅上限。
6. 默认先按六类孢粉、再按组内顺序排列。完整分组优先模式尽量在组边界换排，可能比均衡模式增加排数；超过上限的大组内部均衡拆分。“手动分排”窗口可勾选从哪个类群开始新排，各排仍受上限限制，并提供均衡初始化。左侧“组内上移/下移”调整展示顺序；同组跨排时重复显示组名并标注“续”。
7. 提供实心方块、实心圆、空心圆、三角形、菱形、短横线和短竖线，共 7 种符号。默认黑色实心方块、大小 2 磅，可调 .5—8 磅。可统一设置，也可在“设置各组检出符号”中分别指定六组符号；缺失标记始终为 ×。可选择统一颜色或沿用孢粉六组配色。
8. 默认图宽 18.3 厘米，每排绘图区高 6.2 厘米，图高按实际排数、名称长度和间距自动计算。名称默认 65°、7.5 磅，西文可斜体；刻度 7 磅、轴标题 8 磅，坐标及分组线宽 .6 磅。可手动调整各项设置与总图高，过小尺寸会提示增大；采样密集时可减小符号或增大每排图高以减少重叠。
9. “纵轴坐标设置”可指定最小值、最大值、刻度间隔及递增方向，所有排同步。样品按真实坐标定位。纵轴范围仅裁切显示，不改变参与样品、检出矩阵及频率的统计范围。“显示现有组合带边界”默认关闭，启用时使用现有有效分带结果，不附加聚类树。
10. “检出矩阵”页显示判定状态，鼠标悬停显示原表行、坐标、原始计数、实际百分比、实际基数及原因。检出表导出包含 1/0/空白矩阵、文字状态、缺失与无法判定原因、原始计数、实际百分比与基数、类群统计、图中分排、样品选择和绘图说明。检出频率 = 检出样品数/有效判定样品数；缺失或无法判定不进入分母，无有效判定时频率留空。
11. 图形可导出单个 PDF/SVG/PNG，图像导出仅生成所选文件；Excel 通过“导出检出表”单独生成。导出恢复完整设置范围，预览的平移、缩放不会裁切输出。设置随项目保存，旧项目打开时初始化默认设置。程序目录附计数方块和百分比圆点两种模式的模拟项目、图和检出表。

## 开发

Python 3.13、PySide6 6.12、openpyxl 3.1.5、Matplotlib 3.11.1、NumPy 2.5.2。

```powershell
python -m pip install --target .deps -r requirements.txt
python main.py
python -m unittest discover -s tests -v
./build.ps1
```

打包需安装 PyInstaller；脚本会收集矢量输出模块和中文翻译资源。测试临时目录不可写时，可将 TEMP/TMP 指向本项目 `build/test-temp`。

`build.ps1` 生成 `dist/v1.0.0/PollenStudio`；验证后运行 `python tools/package_release.py` 生成便携版 ZIP、源代码 ZIP 和 SHA-256 校验文件。程序文件清单为 `文件清单.json`，记录各文件大小和哈希值。每个正式版本使用独立输出目录，旧阶段交付文件保留。

当前不含无约束聚类、浓度与累积速率、年代模型及组合总览堆叠图。不自动给出唯一最佳带数，不提供人工拖拽边界；本阶段使用数值输入进行人工调整。
